# Licences of bundled components

Timbre's own source is [MIT](../LICENSE). These are the licences of the
third-party code that travels inside a release build. [NOTICE.md](../NOTICE.md)
says which component each one applies to.

| File | Applies to |
|---|---|
| `GPL-2.0.txt` | x264 and x265, linked by the FFmpeg libraries PyAV bundles. A downloaded build is a combined work distributed under these terms. |
| `LGPL-2.1.txt` | The FFmpeg libraries themselves. They ship as separate shared libraries, so they can be replaced with a modified version. |
| `Inter-OFL.txt` | The Inter typeface. |
| `EBGaramond-OFL.txt` | The EB Garamond typeface. |

The complete source of the combined work is the repository this file came from:
https://github.com/dpaguba/timbre
